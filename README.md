# Lagrange’s Theorem, Euler’s Theorem, Fermat’s Little Theorem, and RSA: Mathematical Proofs and Computational Verification

This project explores the mathematical foundations of **modular arithmetic and public-key cryptography**, connecting abstract algebra and number theory to practical cryptographic applications. It develops complete mathematical proofs of Lagrange’s theorem, Euler’s theorem, Fermat’s Little Theorem, and the correctness of the RSA encryption and decryption process. Alongside the theoretical work, the project implements modular arithmetic operations from scratch in R and exhaustively verifies key mathematical properties across finite test cases. It also investigates the computational difficulty of integer factorisation through an experimental comparison of factoring times for integers of increasing size, illustrating the mathematical principles underlying RSA security.

## Key Concepts
- Groups, subgroups, and Lagrange’s theorem
- Euler’s theorem and Euler’s totient function
- Fermat’s Little Theorem
- Modular addition, multiplication, exponentiation, and inverses
- RSA key generation, encryption, and decryption
- Mathematical proof of RSA correctness
- Integer factorisation and computational complexity
- Exhaustive computational verification of mathematical properties

## Tools and Technologies
- **Language:** R
- **Approach:** From-scratch implementation of modular arithmetic
- **Verification:** Exhaustive testing over finite input ranges
- **Experimentation:** Integer factorisation and execution-time analysis

## Learning Objectives
- Understand the algebraic structures underlying modular arithmetic.
- Establish the theoretical foundations of Euler’s theorem and Fermat’s Little Theorem.
- Prove why RSA encryption and decryption recover the original message.
- Translate mathematical definitions and theorems into working R implementations.
- Use exhaustive computational testing to validate mathematical properties.
- Investigate the relationship between integer size, factorisation difficulty, and cryptographic security.
